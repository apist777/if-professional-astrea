If Professional ASTREA 開発コンセプト
私たちは何を作るのか

ASTREA FREE Quality Target
「無料だから選ばれるテーマではなく、無料でなくても選ばれるテーマを作る。」

ASTREA FREEは、Project-if最大の営業マンである。
無料版の品質そのものによって、Project-ifと有料製品への信用を作る。


If Professional ASTREAは、単なる「士業向けWordPressテーマ」を作るプロジェクトではない。
専門家が、自分の事業のためのWebサイトを、自分自身で持ち、育てていける環境を作る。
Web制作会社に依頼しなければまともなサイトを持てない、WordPressに詳しくなければ自分では作れない、という壁をできる限り低くする。
そのためにASTREA FREEは、無料版だからという理由で品質や実用性を意図的に落とさない。
FREEだけで、本当に仕事に使えるWebサイトを完成できるものを作る。
________________________________________
FREEは「未完成のPRO」ではない
ASTREA FREEはPROの体験版ではない。
有料版を購入させるために、不自然な機能制限を設けたり、通常必要な機能をPRO限定にしたりすることを基本思想としない。
FREEには、専門家サイトを構築するために必要な道具をきちんと提供する。
その道具を使って、
何を掲載するか。
どんなページを作るか。
どのPatternを使うか。
どんなデザインにするか。
どのようにサイトを組み立てるか。
それを考え、作業するのはユーザー自身である。
だから、
FREEは、作れる。
________________________________________
PROは「制限解除」ではなく「仕事の代行」
PROの商品価値は、FREEに掛けた鍵を開けることではない。
FREEユーザー自身が行う必要のある作業を、専門職に特化したシステムが理解し、自動化する。
行政書士PROなら、
「行政書士とは何をする専門家なのか」
「どんな業務ページが必要なのか」
「どんなサイト構成が適しているのか」
を理解した上でサイト構築を支援する。
だから、
PROは、作ってくれる。
PROが販売するものは、機能の数ではない。
専門家の時間である。
________________________________________
ユーザーにWordPressを勉強させすぎない
ASTREAを使う人の本業はWeb制作ではない。
行政書士なら行政書士業務をするために独立したのであって、WordPressの設定方法を覚えるために独立したわけではない。
したがって、
「WordPressなら普通こうする」
「設定画面から変更できます」
だけで設計を終わらせない。
入力できるものは分かりやすく入力できるようにする。
一度入力した情報は可能な限り再利用する。
機械が判断できるものは機械に判断させる。
ユーザーの本業と関係のない作業を減らす。
これをUX設計の基本とする。
________________________________________
自動化するなら、戻せるようにする
PROはサイトへ大きな変更を加える。
だから便利さだけを追求してはいけない。
ページを一括生成するなら、その前に復元ポイントを作る。
設定を一括変更するなら、失敗した場合の戻り道を用意する。
自動化するならUndoも提供する。
便利さと安全性をセットで設計する。
________________________________________
WordPressの所有者はユーザーである
ASTREAはユーザーのサイトをProject-ifへ依存させるための製品ではない。
Project-ifのライセンスサーバーが停止しても、ユーザーのWebサイトは動き続けなければならない。
PROの契約や更新権が終了したからといって、すでに構築したサイトを壊すような設計にはしない。
ユーザーが作ったコンテンツはユーザーのものであり、ASTREAはそれを人質に取らない。
テーマを変更しても残るべきデータはThemeへ閉じ込めない。
________________________________________
流行は取り入れる。しかし流行に依存しない
ASTREAは公開時点で古く見えるテーマにしない。
2027年に公開するなら、2027年のWebデザイン、UI、タイポグラフィ、アクセシビリティ、WordPressの技術動向を調査し、その時代にふさわしいデザインを採用する。
しかし、一時的な流行だけを追ったテーマにもしてはいけない。
土台は長く使える。
表現は時代に合わせて更新できる。
そのためにStyle Variation、Patterns、Design Systemを活用し、ASTREAそのものを毎回作り直さなくても時代に合わせて進化できる構造を目指す。
________________________________________
専門家サイトであることを忘れない
格好良さだけを目的にしない。
士業・専門家サイトに必要なのは、
信頼できること。
何を相談できるのか分かること。
誰が対応するのか分かること。
相談まで迷わないこと。
である。
デザイン上の流行と、専門家サイトとしての信頼性が衝突した場合は、信頼性と使いやすさを優先する。
________________________________________
機能を増やすことを進化だと思わない
「できるから追加する」は理由にならない。
新しい機能を追加するときは、
これはユーザーの作業を減らすか？
これは専門家サイトを良くするか？
これはASTREAが担当すべき仕事か？
を確認する。
Themeが担当すべきものはThemeへ。
テーマを変更しても残るべきものはCoreへ。
職種固有の自動化はPROへ。
継続的に提供する価値は将来のSubscriptionへ。
責任範囲を守る。
________________________________________
迷ったときの判断基準
開発中に意見が割れたり、機能を入れるか迷ったりしたら、最後はここへ戻る。
FREEだけで、ちゃんと仕事に使えるか。
PROは、本当にユーザーの時間を減らしているか。
専門家の本業と関係のない作業を増やしていないか。
自動化したものを安全に戻せるか。
Project-ifへ不必要に依存させていないか。
数年後も育てられる構造になっているか。
そして最後の一行は、やっぱりこれでいい。
FREEは、作れる。
PROは、作ってくれる。
