# ASTREA 1.0.1 — Release Notes

**Status: Stable / Patch release.** This is a narrow patch release on top of 1.0.0 — no feature changes.

**Release date:** 2026-09-06

## What changed

- Corrected the Theme's and Core's official website links (`Theme URI` / `Author URI` / `Plugin URI`), which previously pointed to an incorrect domain. They now correctly point to Project-if's real website.
- Added an optional, editable theme-author credit ("Theme by Project-if") to the default Footer. This is a default, not a requirement — it can be edited or removed like any other content, using the Site Editor, and will not reappear on its own once removed. It does not affect your own site's copyright, which remains entirely your own.

No functionality, templates, patterns, or Core behavior changed beyond the above.

## Requirements

Unchanged from 1.0.0: WordPress 7.0 or later (tested up to 7.1), PHP 8.3 or later (8.4+ recommended).

## Upgrade notes

- If you have already customized your site's Footer in the Site Editor, this update does not change it — your customization is preserved exactly as you left it, and the new credit will not be added to it automatically.
- If you have not customized your Footer, the new default (including the credit) will appear after updating. You are free to edit or remove it at any time.
