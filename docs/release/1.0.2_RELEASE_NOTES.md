# ASTREA 1.0.2 — Release Notes

**Status: Stable / Patch release (Theme only).** This is a narrow patch on top of 1.0.1 — no feature changes. ASTREA Core is unchanged and remains at 1.0.1.

**Release date:** 2026-09-06

## What changed

Found during a WordPress.org submission-readiness review (Construction Order 022):

- Fixed a reproducible Site Editor warning ("Block contains unexpected or invalid content") that appeared when opening the HOME (Front Page) template. The warning had no visual or functional effect on any site, but was fixed at the source so it no longer appears.
- Removed an unused internal code constant.
- Removed an internal development-document reference from the theme's public description text.

No template, pattern, style, or Core behavior changed beyond the above.

## Requirements

Unchanged from 1.0.1: WordPress 7.0 or later (tested up to 7.1), PHP 8.3 or later (8.4+ recommended).
