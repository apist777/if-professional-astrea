# ASTREA Icon Set

Minimal line icons for If Professional ASTREA.

- Main stroke: #102A43
- Accent stroke: #B99A5C
- ViewBox: 0 0 48 48
- Stroke width: 1.8
- No embedded text
- SVG only
- Designed for theme UI, not content photography

Files:
- company.svg — company formation / office / corporation
- permit.svg — permits / applications
- inheritance.svg — inheritance / family support
- contract.svg — contracts / legal review
- result-company.svg — company-support result metric
- result-check.svg — approval / success result metric
- result-consultation.svg — consultations / clients result metric
- price-yen.svg — fees / pricing
- document.svg — documents / applications
- folder.svg — document management / case files

Implementation note:
If you want variation-controlled colors via CSS, inline the SVG markup and replace the
hard-coded stroke colors with CSS variables or `currentColor`. Keeping these files as
external <img> assets preserves the designed navy/gold appearance.
